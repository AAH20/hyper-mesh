# hyper-mesh

> **Broker-Free P2P Kademlia Mesh Network for Distributed Frontier Agent Swarms**

Engineered for September 2026 distributed swarms spanning edge and cloud nodes (**DeepSeek V4.1-Flash**, **GPT-6 Sol**, **Claude Opus 5.5**, **Gemini 3.8 Flash Cyber**).

## Features
- **Kademlia DHT Peer Discovery**: Zero central servers; decentralized logarithmic XOR routing table.
- **Gossip Consensus & Task Auction**: Distributed bidding engine optimizing for latency, price, and node reputation.
- **Model Affinity Routing**: Directs heavy reasoning tasks to cloud nodes and low-latency micro-tasks to edge nodes automatically.

## Installation
```bash
pip install -e .
```
